## ✨ Features & Framer Aesthetics

- **Framer Signature Framing**: Refined outer framed border (`#bfbfbf`), rounded inner canvas corners (`16px`), and high-end typography (`Space Grotesk`, `Geist`, `Inter`).
- **Signature Word-by-Word Scroll Reveal**: About Me section with dynamic scroll-driven illumination from subtle muted gray into high-contrast dark with electric orange keyword accents.
- **Giant Hero Headline**: Staggered letter-by-letter entrance animation with blur-to-clear physics.
- **Interactive 3D Digital Twin Canvas**: Real-time rotating cybernetic icosahedron with telemetry nodes powered by Three.js (with canvas fallback).
- **Infinite Marquee Ticker**: Smooth continuous scrolling tech stack ticker with faded gradient edges.
- **4-Card Service Grid**: Styled identically to the Ruhi template with numbered tags `(01)` to `(04)`, orange title hover translations, and inner card elevation.
- **Interactive Project Showcase**: High-res mockups with 3D perspective mouse tilt, hover zoom, direct links to live docs & GitHub repositories, and interactive case study modal dialogs.
- **Professional Experience Timeline**: Comprehensive breakdown of 2.5 years at Zifo Technologies (ThermoFisher partner network), open-source Meika Security Suite, and freelance 3D engineering with repository links.
- **Collaborator Reviews Carousel**: Touch-swipeable and button-navigated carousel with auto-play and pause on hover.
- **Verified Credentials & Certifications**: Microsoft Certified AZ-900, SC-900, Outskill AI Generalist, and SIH 2022 Hardware 1st Prize.
- **Ruhi Mega Menu Drawer**: Dropdown drawer with white border frame, menu links, social options, live docs badge, and direct contact details.
- **Interactive Contact Form & Quick-Copy**: Functional form with appointment/service selector and one-click copy for email and phone.

## 🚀 How to Run

### Option 1: Direct File Open (Zero Setup)
Simply double-click or open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Port 3000)
Run using Node.js:
```bash
node serve.js
# Or
npm start
```
Then visit: [http://localhost:3000](http://localhost:3000)
