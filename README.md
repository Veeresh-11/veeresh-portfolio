# Veeresh Babu V K — Portfolio

Personal portfolio of **Veeresh Babu V K**, a Full-Stack Cloud Developer based in Madurai, India. Rebuilt as a React + Vite + Tailwind CSS single-page app.

## Stack

- React 19 + Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`)
- TypeScript 5.7
- Fonts: Archivo (display), JetBrains Mono, Inter — loaded via Google Fonts

## Highlights

- Custom animated cursor, magnetic buttons, scroll reveals, count-up stats, keyword marquee
- Warm cream + vermilion light theme
- Experience section spotlighting the Zifo Technologies role (Analyst — LIMS Software Engineer, Jun 2023 – Sep 2025, 2.5 years .NET)
- Meika Security Suite featured project with a live embed of the platform

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
